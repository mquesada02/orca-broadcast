# `--reason` on `broadcast`

`broadcast` does not accept `--reason`. Only `pause` takes it.

## Why this is out of scope

On `pause`, `--reason` picks a fixed pause sentence and the matching continue sentence that `resume` sends later. The pause message is generated by the tool, so a preset is the only way for the user to change its first sentence.

A broadcast is different: its whole text is written by the user. A preset would only put a fixed sentence before text that the user already controls, for example:

```
orca-broadcast broadcast "The user is leaving and the network will drop. Stop at the next safe point."
```

The same result needs no flag. A broadcast also has no later "continue" step, so the second half of a preset has no use.

The specs #61, #81 and #88 already listed this as out of scope.
